# Second Brain — Build Prompt for Claude Co-Work

A copy-paste prompt for Elizabeth Reed to send to Claude Co-Work so it will
design and build a working "second brain" (personal knowledge system).

Defaults: Notion as the home, PARA as the backbone, framed as a personal +
work knowledge system. Runs in phases with approval checkpoints and concrete
database schemas. Adjust to taste before sending.

---

**MISSION**

You're helping me build a **second brain** — one trusted system that captures
what I'm working on and thinking about, connects it, and makes it easy to find
and turn into output. Optimize for a system I'll actually use every day, not an
elaborate one I'll abandon. One system, one source of truth.

**HOW TO WORK WITH ME**

- Work in the phases below and stop at each checkpoint. Don't build everything
  before I've approved the plan.
- Favor simple and durable over clever — fewer databases, more connections.
- Confirm before creating or changing anything at scale. Never move, overwrite,
  or delete existing content without asking first.
- Build real, working pages and databases — not descriptions or mockups.
- Use my actual tools. When something's ambiguous, ask one sharp question
  instead of guessing.

**PHASE 1 — DISCOVER** *(do this first, then wait for me)*

1. Tell me which tools you can connect to (Notion, Google Drive, Gmail,
   Calendar, task apps, meeting notes, etc.).
2. Recommend where the second brain should live and why — default to Notion
   unless a better option is obvious.
3. Ask me:
   - What I'll mainly use it for (work/clients, personal, research, writing, or
     all of it).
   - What I already use that we should import or link to.
   - Whether it's just for me or shared with a team.
   - Anything that must NOT be changed or moved.

**PHASE 2 — PROPOSE** *(checkpoint — get my yes before building)*

Show me the plan on one screen: the databases you'll create, how they relate,
and what my home dashboard will look like. Wait for my approval.

**PHASE 3 — BUILD the structure**

Use **PARA** as the backbone. Create these as **linked databases** (not
folders), each with the fields listed:

- 📥 **Inbox** — the default capture spot; everything can start here.
  *Fields: Title · Type · Captured date · Status (Unprocessed / Processed).*
- 🚀 **Projects** — a goal with a deadline.
  *Fields: Name · Status (Not started / Active / On hold / Done) · Area
  (relation) · Outcome · Next action · Due date · Priority · → Tasks · → Notes
  · → People.*
- 🗺️ **Areas** — ongoing responsibilities, no end date.
  *Fields: Name · Description · Review cadence · → Projects · → Notes.*
- 📚 **Resources** — reference material by topic.
  *Fields: Name · Type (Article / Template / Tool / Book / Swipe) · Topic ·
  Link · Tags · → Areas / Projects.*
- 🗄️ **Archive** — completed or inactive items, out of the way but searchable.
  (Prefer a status/toggle over a separate silo if that's cleaner.)

Connective layer:

- 🧠 **Notes** — atomic (one idea per note).
  *Fields: Title · Type (Idea / Reference / Meeting / Permanent) · Tags ·
  Source · Status · → Projects · → Areas · → People · → Related notes
  (self-relation).*
- 👥 **People** — a lightweight CRM.
  *Fields: Name · Role/Company · Relationship · Last touchpoint · Context ·
  → Projects · → Notes.*
- ✅ **Tasks** — one list, rolled up from Projects.
  *Fields: Task · Status · Priority · Do date · Due date · → Project.*
- 📅 **Daily Notes** — a dated log for capture, journaling, and meeting notes.
  *Fields: Date · Log · → People · → Projects · → Meetings.*

**PHASE 4 — WIRE IT UP + SEED**

- Connect the relations so Notes, Projects, People, and Areas cross-reference
  each other automatically (backlinks both ways).
- Build a 🏠 **Home dashboard** as my front door: Today's tasks · Active
  projects · Inbox to process · Recently captured · quick links to every
  database.
- Add saved views where useful: **Today**, **This Week**, **Active**,
  **Inbox (unprocessed)**, **By Area**.
- Add 2–3 realistic example entries per database so I can see the flow — use my
  real context where you can, clearly marked as examples.
- If you can, pull in what already exists (recent docs, meeting notes,
  contacts) to link — but ask before importing anything in bulk.

**PHASE 5 — HAND OFF**

- Create a **Weekly Review** page with a 5-minute checklist: empty the Inbox,
  update project statuses, archive finished work, review People I owe a
  follow-up, plan the week.
- Give me a short **"How to use this"** guide: where to capture (the one
  place), how to find things (search + views), how a note moves from Inbox to
  its right home, and the weekly habit that keeps the system alive.

**DONE WHEN**

- I can capture in one click, find anything in seconds, and everything is
  connected.
- The home dashboard shows what matters today.
- I have a weekly habit and a one-page guide.

Keep it clean and minimal, and check with me before anything destructive or
large-scale.
