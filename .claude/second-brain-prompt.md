# Second Brain — Build Prompt for Claude Co-Work

A copy-paste prompt for Elizabeth Reed to send to Claude Co-Work so it will
design and build a working "second brain" (personal knowledge system).

Defaults: Notion as the home, the PARA method as the backbone, framed as a
work + personal knowledge system. Claude confirms a few essentials before
building. Adjust to taste before sending.

---

Hi Claude — I'd like you to help me build a **second brain**: one well-organized
knowledge system that captures everything I'm working on and thinking about,
keeps it connected, and makes it easy to find and act on later. I want a system
I'll actually use, not a beautiful thing I'll abandon.

**Before you build anything, ask me these questions and wait for my answers:**

1. **Where should it live?** (e.g., Notion, Google Drive/Docs, or somewhere else
   you can connect to.) If I don't have a preference, recommend the best option
   based on the tools you can access — default to Notion.
2. **What will I mainly use it for?** (e.g., work projects, clients, personal
   life, research, writing — or all of the above.)
3. **What do I already use** that we should pull in or link to? (existing notes,
   docs, calendars, email, task apps.)
4. **Just me, or shared with a team?**

**Then build it using the PARA method as the backbone** (adapt the names to fit
my answers):

- **📥 Inbox / Capture** — one frictionless place to dump any note, idea, link,
  or task without deciding where it goes yet. This is the default landing spot.
- **🚀 Projects** — things with a goal and a deadline. Each is its own page with
  status, due date, linked notes, and next actions.
- **🗺️ Areas** — ongoing responsibilities with no end date (Health, Finances, a
  client relationship, Marketing, etc.).
- **📚 Resources** — reference material by topic: notes, saved articles,
  templates, how-tos, swipe files.
- **🗄️ Archive** — completed projects and inactive items, out of the way but
  still searchable.

**Also create these connective pieces:**

- **🧠 Notes** — atomic notes (one idea per note) that link to Projects, Areas,
  Resources, and People. Include tags and a "related notes" relation so ideas
  connect to each other.
- **👥 People** — a lightweight CRM: who I know, context, last touchpoint, and
  links to related notes and projects.
- **✅ Tasks** — a single task list that rolls up from Projects, with status,
  priority, and due dates.
- **📅 Daily Notes** — a dated log for meeting notes, thoughts, and daily
  capture, linked back to the relevant projects and people.
- **🏠 Home dashboard** — the front door I open first each day: today's tasks,
  active projects, recent captures, and quick links to everything.

**Make it actually work, not just exist:**

- Make capture effortless — one obvious "add to Inbox" entry point.
- Use relations/links (not just folders) so notes, projects, people, and areas
  cross-reference each other.
- Add a **Weekly Review** page with a simple checklist: process the Inbox to
  zero, update project statuses, archive what's done, plan the coming week.
- Keep it minimal. I'd rather have a simple system I'll use than a complex one
  I'll abandon.

**As you build:**

- Show me the structure/plan first and let me approve before you create
  everything.
- Create real, usable pages and databases (not just descriptions), with a few
  example entries so I can see how it flows.
- When you're done, give me a short **"how to use this"** guide: where to
  capture, how to find things, and the weekly habit that keeps it alive.
