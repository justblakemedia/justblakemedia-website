How to read these

What "conservative floor" means, and why the page says it.

The property management ads promoted listings that later leased, but signed leases were not tracked as direct Meta conversions. So the return shown is influenced value compared with spend, counted as one month's commission plus the application fee, with most rents individually confirmed. Not proven last-click return on ad spend. A number you can divide is worth more than a number you have to trust.
